## 📋 Descripción

Lector NFC es una aplicación web progresiva (PWA) que permite leer etiquetas NFC directamente desde el navegador de tu dispositivo móvil. Utiliza la moderna API Web NFC para proporcionar una experiencia fluida y detallada en la lectura de diferentes tipos de etiquetas NFC.

### ✨ Características Principales

- 📡 **Lectura en tiempo real** de etiquetas NFC
- 📊 **Visualización detallada** de todos los datos de la etiqueta
- 📦 **Soporte para múltiples tipos** de registros NDEF (Texto, URL, Smart Poster, MIME)
- 🎨 **Interfaz intuitiva y responsive** que se adapta a cualquier dispositivo
- 🔒 **Seguro**: Solo funciona en contextos HTTPS (requerido por la API Web NFC)
- 📱 **Diseño mobile-first** optimizado para smartphones
- ⚡ **Rápido y ligero**: Sin dependencias externas

## 🚀 Requisitos del Sistema

### Hardware Necesario
- Dispositivo Android con chip NFC
- El NFC debe estar activado en los ajustes del dispositivo

### Software Necesario
- **Navegador**: Google Chrome 89 o superior
- **Sistema Operativo**: Android 6.0 (Marshmallow) o superior
- **Conexión**: HTTPS o localhost (obligatorio para Web NFC)

> ⚠️ **Importante**: La API Web NFC solo está disponible en Android con Chrome. No funciona en iOS (iPhone/iPad) ni en navegadores de escritorio.
